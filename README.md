# 景观规范速查

为风景园林 / 环境设计从业者与学生打造的规范条文速查工具。输入关键词（如"综合公园规模""盲道""沙池""绿地率"），即可查到相关规范的条文要点与关键指标。

🌐 **在线演示**：（在仓库 Settings → Pages 开启后，把地址填到这里）

## 功能

- **关键词速查**：按问题、关键词、规范编号智能匹配，关键数字（面积、坡度、比例）高亮显示
- **规范清单**：常用规范按编号列出，可按标签筛选
- **手机优先**：H5 页面，工地、课堂上都能用
- **纯静态**：无后端，打开即用，也可离线使用（双击 `index.html`）

## 数据说明

- 内置 20 条种子知识（`data/kb.json`），覆盖：规范清单、绿地分类、公园规模与用地、儿童活动场地、无障碍、居住区与道路绿化、园林城市指标、绿线、标识、海绵城市、绿道
- 每条均注明来源规范编号（如 GB 51192-2016）
- ⚠️ 条目为**要点摘要**，非规范全文；**具体条文以规范原文为准**

## 本地运行

直接用浏览器打开 `index.html` 即可（内置数据兜底，离线可用）。

如需调试外部数据加载，用任意静态服务器，例如：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 如何贡献

欢迎补充规范条目！详见 [CONTRIBUTING.md](CONTRIBUTING.md)。简单说：

1. Fork 本仓库
2. 按格式往 `data/kb.json` 追加条目
3. 提 Pull Request
